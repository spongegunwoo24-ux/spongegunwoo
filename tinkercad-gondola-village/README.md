# 산비탈 마을 · 수소 트램 · 곤돌라 디오라마 (Tinkercad용)

![미리보기](preview.png)

**왼쪽 언덕:** 계단 없이 매끈하게 이어진 비탈이에요. 붉은 벽돌과 밝은 색 벽의 3~4층 필로티 빌라가 빽빽해요.
1층은 기둥만 있는 주차장이고, 평평한 옥상에 작은 물탱크가 있어요.

**수소 트램:** 언덕 앞쪽에 언덕 아래부터 꼭대기까지 오르는 선로가 있고, 수소 트램 한 대가 올라가고 있어요.
- 큰 창문 안으로 작은 분수 장치가 보여요.
- 옆구리 노즐에서 길가 화단으로 물줄기를 뿌려서, 내뿜는 게 물뿐이라는 걸 보여 줘요.
- 지붕에는 수소 탱크가 있어요.

**가운데:** 파란 강과 작은 나무다리가 있어요.

**강 건너:** 빨간 십자가가 있는 하얀 병원, 지하철 출입구, 알록달록한 지붕의 작은 시장이 있어요.

**곤돌라:** 언덕 꼭대기 정거장과 병원 옆 정거장을 일직선으로 잇고, 두 정거장 지붕은 태양광 패널로 덮었어요.
곤돌라 칸 하나에는 휠체어 탄 사람이 타고 있어요. 둥근 로우폴리 나무도 몇 그루 있어요.

- 크기: **180 × 120 mm**, 높이 약 60 mm (Tinkercad 기본 작업판 200×200 안에 들어갑니다)
- 글자는 넣지 않았습니다.

## Tinkercad로 가져오기

### 빠르게 (한 덩어리)
1. Tinkercad 디자인 화면 오른쪽 위 **가져오기(Import)** 클릭
2. `all_in_one.stl` 선택 → 단위 **밀리미터**, 크기 **100%** → 가져오기
3. 전체가 한 색으로 들어옵니다.

### 색깔까지 살리기 (추천)
1. `tinkercad_parts.zip`을 받아 압축을 풀거나 `stl/` 폴더의 파일을 씁니다.
2. 파일 24개를 **하나씩 가져오기** 합니다 (단위 mm, 100%).
3. 각 파일은 아래 표의 색으로 바꿉니다 (도형 선택 → 색상 → 사용자 지정에 HEX 입력).
4. 가져온 위치가 어긋나 있으면 전부 선택(Ctrl+A) → **정렬(L)** 로 가운데·가운데 정렬하면 딱 맞습니다.
   모든 파일의 바닥 크기가 바닥판과 똑같도록, 바닥판 모서리 속에 0.3 mm짜리 숨은 정렬 조각을 넣어 두었습니다.

## 다시 만들기 / 고치기

`generate.py`가 모든 STL과 미리보기 그림을 만듭니다.
- `HILL_TOP`, `slope_profile`: 언덕 높이와 비탈 모양
- `COLS`, `ROWS`: 빌라 배치
- `hydrogen_tram(-38.0)`: 트램 위치 (숫자가 x 좌표)

```bash
pip install numpy scipy matplotlib pillow
python3 generate.py          # PREVIEW=0 으로 미리보기 생략
```

## 3D 프린팅 참고

화면용 디오라마 기준이라 케이블(지름 0.7 mm)·물줄기·꽃·휠체어·사람 같은 부품은 아주 가늘어요.
프린트한다면 Tinkercad에서 전체 크기를 키우거나, 케이블을 굵은 원기둥으로 바꿔 주세요.
