# 1-2comunity

## 믹스테이프 데크 (`mixtape/`)

곡 목록을 한 줄에 하나씩 붙여넣으면 유튜브에서 찾아 한 곡씩 이어서 틀어주는 재생 데크.

- **사용법**: `mixtape/index.html`을 브라우저로 열고, 곡 목록을 붙여넣은 뒤 `큐에 추가`를 누릅니다.
- **입력 형식**: `아이유 - 밤편지` 처럼 제목만 써도 되고, 유튜브 링크(`https://youtu.be/...`)를 바로 넣어도 됩니다.
- **자동 검색**: 제목만 적은 줄을 유튜브에서 자동으로 찾으려면 [YouTube Data API v3](https://console.cloud.google.com/) 키가 필요합니다. 페이지 안에서 등록하며, 키는 브라우저 `localStorage`에만 저장됩니다.
- **키 없이 쓰기**: 각 곡의 🔗 버튼을 눌러 유튜브 링크를 직접 붙여넣으면 그대로 재생됩니다.
- 큐·볼륨·반복·섞기 설정과 한 번 찾은 곡은 브라우저에 저장되어 다음에 열 때 그대로 남습니다.

GitHub Pages를 켜면 `https://<사용자>.github.io/spongegunwoo/mixtape/` 로 어디서든 열 수 있습니다.
