# 1-2comunity

## 믹스테이프 데크 (`mixtape/`)

곡 목록을 적으면 한 곡씩 이어서 틀어주는 플레이어. 네 개의 페이지가 각각 다른 재생 경로를 씁니다.
모두 파일 하나짜리 정적 HTML이라, 브라우저로 열기만 하면 되고 설치할 것이 없습니다.

| 파일 | 하는 일 | 필요한 것 |
| --- | --- | --- |
| `check.html` | 이 네트워크에서 어떤 재생 경로가 실제로 되는지 검사 | — |
| `files.html` | 내 컴퓨터의 음악 파일을 순서대로 재생 | 음악 파일. **인터넷 불필요** |
| `links.html` | 오디오 주소·인터넷 라디오를 순서대로 재생 | 해당 주소가 열리는 망 |
| `index.html` | 곡 제목을 유튜브에서 찾아 순서대로 재생 | 유튜브 영상 재생이 되는 망 |

### 어느 걸 쓸지

`check.html`을 먼저 열어 **연결 검사**를 돌리세요. 결과에 따라:

- 유튜브 재생 검사가 통과 → `index.html`
- 유튜브는 막혔는데 오디오 주소 검사가 통과 → `links.html`
- 둘 다 막힘 → `files.html` (인터넷을 전혀 쓰지 않아 항상 동작)

### `index.html` — 유튜브

- 한 줄에 한 곡. 제목 텍스트, 유튜브 URL, 11자리 영상 ID를 모두 인식합니다.
- **검색 (기본, 키 불필요)**: `공개 서버` 모드는 Piped·Invidious 공개 미러로 제목을 검색합니다. 미러는 자원봉사 운영이라 종종 죽어서, 실패하면 다음 서버로 자동으로 넘어가고 필요하면 살아있는 서버 목록을 새로 받아옵니다. 검색어는 해당 미러 서버로 전송됩니다.
- **검색 (API 키)**: [YouTube Data API v3](https://console.cloud.google.com/) 키를 쓰면 가장 정확합니다. 하루 검색 약 100회 한도. 키는 브라우저 `localStorage`에만 저장됩니다.
- **수동 지정**: 각 곡의 🔗 버튼으로 유튜브 링크를 직접 넣으면 검색 없이 재생합니다.
- 연속 3곡이 실패하면 멈추고 원인을 알려줍니다.

### `files.html` — 내 음악 파일

- 폴더나 파일을 고르거나 창에 끌어다 놓으면 하위 폴더까지 훑어 목록을 만듭니다.
- mp3 · m4a · flac · ogg · opus · wav. 제목·아티스트·앨범 이미지는 파일 태그에서 읽고, 없으면 파일 이름으로 대신합니다.
- 크롬·엣지에서는 고른 폴더를 기억해 두었다가 다음에 버튼 한 번으로 다시 엽니다.
- 파일은 브라우저 밖으로 나가지 않고, 네트워크를 전혀 쓰지 않습니다.

### `links.html` — 링크 · 라디오

- 한 줄에 하나. `제목 | 주소` 또는 주소만. `.m3u` · `.pls` 내용을 그대로 붙여넣어도 읽습니다.
- `전부 확인`으로 각 주소가 이 망에서 실제로 재생 가능한지 미리 검사합니다.

### `check.html` — 진단

- 주요 사이트에 실제로 닿는지, 유튜브 임베드가 재생까지 되는지, 오디오 주소와 내 파일이 열리는지 차례로 검사하고 어느 페이지를 쓰면 되는지 알려줍니다.

### 공통

- 재생/정지 · 이전/다음 · 섞기 · 반복(전체/한 곡/끄기) · 볼륨 · 드래그 탐색.
- 단축키 `Space` `N` `P` `M` `←` `→`.
- 목록과 설정은 브라우저 `localStorage`에 저장됩니다.
- 라이트·다크 테마, 모바일 폭 대응.

### 중요 — `index.html`은 웹 주소로 열어야 합니다

유튜브 임베드 플레이어는 `http://` 또는 `https://` 출처를 요구합니다. 파일을 더블클릭해서
`file://` 로 열면 유튜브가 출처를 확인하지 못해 **오류 153 (동영상 플레이어 구성 오류)** 이 나고
어떤 곡도 재생되지 않습니다. 네트워크 차단과는 다른 문제이며, 페이지가 이 상태를 감지해 안내합니다.

해결 방법 둘 중 하나:

- **GitHub Pages** — 저장소 Settings → Pages 에서 브랜치를 지정하면
  `https://<사용자>.github.io/spongegunwoo/mixtape/index.html` 로 열립니다.
- **로컬 서버** — 파일이 있는 폴더에서 `python3 -m http.server 8000` 을 실행하고
  `http://localhost:8000/index.html` 로 엽니다.

다른 흔한 실패: **곡은 `준비됨`인데 재생 버튼이 “플레이어를 불러오는 중이에요”만 반복**하는 경우.
검색은 공개 미러로 하고 재생만 유튜브 스크립트에 의존하기 때문에, 광고 차단 확장 프로그램이나
방화벽이 `youtube.com/iframe_api` 를 막으면 이 상태가 됩니다. 9초 뒤 **예비 경로**로 자동 전환합니다:
공식 API 대신 `youtube-nocookie.com` 임베드를 직접 띄우고 `postMessage` 로 재생·정지·탐색·곡 종료를
처리합니다. 차단기가 스크립트만 막고 임베드는 통과시키는 환경에서는 이 경로로 재생됩니다.
임베드까지 막히면 14초 뒤 그 사실을 알리고 다음 곡으로 넘어갑니다.

`files.html` · `links.html` · `check.html` 은 `file://` 로 열어도 정상 동작합니다
(단 `check.html` 의 유튜브 재생 검사만 위와 같은 이유로 153이 납니다).
