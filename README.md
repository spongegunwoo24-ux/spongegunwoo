# 1-2comunity

## 믹스테이프 데크 (`mixtape/`)

곡 목록을 한 줄에 하나씩 붙여넣으면 유튜브에서 찾아 한 곡씩 이어서 틀어주는 재생 데크.

- **사용법**: `mixtape/index.html`을 브라우저로 열고, 곡 목록을 붙여넣은 뒤 `큐에 추가`를 누릅니다.
- **입력 형식**: `아이유 - 밤편지` 처럼 제목만 써도 되고, 유튜브 링크(`https://youtu.be/...`)를 바로 넣어도 됩니다.
- **검색 (기본, 키 불필요)**: `공개 서버` 모드는 Piped·Invidious 공개 미러로 제목을 검색합니다. 목록을 붙여넣고 `전부 검색`만 누르면 됩니다. 미러는 자원봉사 운영이라 종종 죽어서, 실패하면 다음 서버로 자동으로 넘어가고 필요하면 살아있는 서버 목록을 새로 받아옵니다. 검색어는 해당 미러 서버로 전송됩니다.
- **검색 (API 키)**: `API 키` 모드는 [YouTube Data API v3](https://console.cloud.google.com/) 키를 씁니다. 가장 정확하지만 하루 검색 약 100회 한도가 있고, 조직 계정에서는 발급이 막혀 있을 수 있습니다. 키는 브라우저 `localStorage`에만 저장됩니다.
- **수동 지정**: 각 곡의 🔗 버튼을 눌러 유튜브 링크를 직접 붙여넣으면 검색 없이 그대로 재생됩니다.
- 큐·볼륨·반복·섞기 설정과 한 번 찾은 곡은 브라우저에 저장되어 다음에 열 때 그대로 남습니다.

GitHub Pages를 켜면 `https://<사용자>.github.io/spongegunwoo/mixtape/` 로 어디서든 열 수 있습니다.
