# 선셋 서킷

단일 HTML 파일로 만든 정통 3D 레이싱 게임. 외부 라이브러리·이미지·음원을 쓰지 않는다.
도로는 세그먼트 원근 투영(의사 3D)으로 그리고, 커브·언덕·길가 오브젝트·상대 차가 전부 절차적으로 배치된다.

## 실행

`index.html`을 브라우저로 열면 끝.

## 조작

| 입력 | 동작 |
|---|---|
| `↑` / `W` | 가속 (기본은 자동 가속) |
| `↓` / `S` | 브레이크 |
| `←` `→` / `A` `D` | 조향 |
| 모바일 | 화면 좌·우 절반 터치로 조향, 하단 중앙 터치로 브레이크 |

## 규칙

- 3랩 주행. 랩마다 시간이 기록되고 베스트 랩이 표시된다.
- 코스를 벗어나면 급격히 느려진다(완전히 서지는 않는다).
- 코너에서는 원심력으로 바깥으로 밀린다. 속도가 붙을수록 강해진다.
- 앞차에 부딪히면 속도가 앞차 수준으로 떨어지고 옆으로 튕긴다.
