# Age of Civilizations (원작) — 게임 상세 묘사

> 대상: 2014년 무렵 Łukasz Jakowski가 만든 안드로이드/PC용 턴제 세계정복 게임 **Age of Civilizations** (후속작 *Age of Civilizations II*와 구분되는 1편).
>
> 표기 규칙
> - **[원작]** : 원작 설명·커뮤니티 기록으로 확인되는 내용
> - **[추정]** : 원작 화면/플레이 경험을 바탕으로 재구성한 내용. 정확한 수치·공식은 공개된 적이 거의 없으므로, 구현할 때는 "그럴듯한 기본값"으로 취급할 것.

---

## 0. 한 문장 요약

거대한 세계지도를 수백 개의 province로 나누고, 각 province 위에 **"국가 색 + 병력 숫자"** 만 올려 둔 뒤,
플레이어가 매 턴 제한된 Movement Points로 **이동·모집·외교 명령**을 제출하면 세계 전체가 한꺼번에 시뮬레이션되는 게임.
재미의 본질은 **"내 색깔이 세계지도 위로 번져 나가는 것"** 이다.

---

## 1. 게임을 켰을 때 — 메뉴 흐름

```
[타이틀 화면]
 ├─ New Game ─────────► 시나리오 선택 → 문명 선택 → 게임 설정 → 게임 시작
 ├─ Load Game
 ├─ Editor
 │   ├─ Civilization Creator   (국가 만들기: 이름/색/국기/태그)
 │   ├─ Scenario Editor        (시작 연도, 어떤 국가가 어떤 province를 가지는지, 수도, 관계)
 │   └─ Map Editor / Formable 등 [추정: 버전에 따라 범위 다름]
 ├─ Settings (언어, 그래픽, 사운드, 자동저장 등)
 └─ Exit
```

### 1-1. 시나리오 선택
- **[원작]** 미리 만들어진 시작 상태(시나리오)를 고른다. 대표적으로 "현대 세계" 같은 실제 국경 기반 시나리오가 있고, 사용자가 에디터로 만든 시나리오(역사적 연도, 가상 세계 등)도 불러올 수 있다.
- 시나리오가 정하는 것: 등장 국가 목록, 각 province의 소유자, 각 국가의 수도, 초기 병력, 초기 외교 관계(동맹·종속 관계 등).

### 1-2. 문명 선택
- 세계지도가 그대로 보이고, 지도에서 국가를 **탭**하면 그 국가가 선택된다.
- 화면 한쪽에 선택한 국가의 **국기, 이름, province 수, 인구, 경제** 같은 간단한 요약이 뜬다.
- 혼자 할 수도 있고, **[원작]** 같은 기기에서 여러 명이 각각 국가를 맡는 **Hot-seat(핫시트) 멀티플레이**가 가능했다. 턴이 넘어갈 때 다음 플레이어로 화면이 넘어간다.

### 1-3. 게임 설정 (시작 전 옵션)
| 옵션 | 내용 |
|---|---|
| Fog of War | `OFF` / `STANDARD` / `FULL` — 시야 제한 정도 **[원작]** |
| AI 공격성/난이도 | AI가 얼마나 자주 전쟁을 거는지 **[추정: 버전별 차이]** |
| 중립 지역 처리 | 시나리오에 정의된 미점유 지역을 그대로 두는지 |
| 승리 조건 | 기본은 세계정복(모든 문명 제거) **[추정]** |

### 2-1. 지도 자체
- 지구가 **수백 개(시나리오에 따라 대략 수백~천 단위)의 province**로 잘게 쪼개져 있다. **[추정: 정확한 개수는 맵 버전별로 다름]**
- 각 province는 **소유 국가의 색으로 단색 채우기**. 국경선은 얇은 선, 국가 간 경계는 색 차이로 자연스럽게 보인다.
- **중립/미점유 province**는 색이 없는(투명/회색) 상태로 남아 있다. **[원작]**
- 바다는 파란 배경. 바다도 일부 구역(sea province)으로 나뉘어 있어서 해상 이동의 "칸" 역할을 한다. **[원작]**
- **핀치 줌 / 드래그 스크롤** 로 세계 전체 ↔ 한 지역 클로즈업을 오간다. 축소하면 숫자가 겹치지 않도록 일부만 표시되거나 작게 표시되는 식. **[추정]**

### 2-2. 지도 위의 숫자
- 병력이 있는 province 중앙에 **흰색/검은 테두리의 숫자**가 떠 있다. 이것이 곧 군대다.
- 숫자 옆이나 뒤에 **소유국의 작은 국기**가 붙어 보이는 형태. **[추정: 버전에 따라 국기 아이콘 유무 다름]**
- 내 병력 숫자와 적 병력 숫자가 지도 위에서 확연히 구분된다.
- 이동 명령을 내리면 **출발 province → 도착 province 사이에 화살표**가 그려지고, 화살표 위에 이동할 병력 숫자가 붙는다.

### 2-3. 수도와 건물 아이콘
- 수도 province에는 **별/왕관 같은 수도 마크**. **[추정: 아이콘 모양]**
- Fort(요새), Watch Tower(감시탑), Port(항구)가 지어진 province에는 **작은 건물 아이콘**이 붙는다.

## 3. 조작 감각 — 손가락으로 무엇을 하는가

모든 조작은 **"province를 누른다 → 명령을 고른다 → 대상 province를 누른다 → 숫자를 정한다"** 의 반복이다.

```
① 내 province 탭
     → 하단에 그 province 정보 팝업
       (이름 / 소유국 / 인구 / 병력 / 건물 / 지형)

② [Move] 선택
     → 이동 가능한 이웃 province들이 하이라이트

③ 목적지 province 탭

④ 슬라이더 등장
     0 ─────────●────────── 1000
               [ 600 ]
     → 보낼 병력 숫자 결정

⑤ 확인
     → 지도에 화살표 생성, MP 차감
     → 출발지 숫자는 아직 안 줄어든 채(또는 예약 표시) 턴 종료를 기다림 [추정]
```

- 같은 방식으로 **Recruit**는 "province 탭 → Recruit → 슬라이더로 모집 수 결정",
  **Build**는 "province 탭 → Build → 건물 선택",
  **Diplomacy**는 "다른 나라 province 탭 → 외교 버튼 → WAR/PEACE/…" 순서.
- 명령은 **즉시 실행되지 않는다.** 턴 종료 버튼을 누를 때까지 "예약 목록"에 쌓인다. 예약한 명령은 취소할 수 있다. **[추정: 취소 UI 형태]**

## 4. 기본 단위: Province

세계는 하나의 덩어리가 아니라 **province의 그래프**다.

```
Province
├─ id
├─ name                 (예: "Seoul", "Gyeonggi" 같은 지역명)
├─ owner                (국가 id 또는 NONE=중립)
├─ population           (인구 — 병력과 돈의 원천)
├─ economy              (경제 수치 — 세금의 원천) [추정: province 단위 or 국가 단위]
├─ army[]               (이 province에 주둔한 병력. 국가별로 여러 개일 수 있음)
├─ terrain              (평원/산/숲/사막 등 — 전투 보정) [원작: Terrain map mode 존재]
├─ buildings            (Fort / WatchTower / Port)
├─ is_capital
├─ is_sea
└─ neighbors[]          (육상 인접 + 해상 인접)
```

### 4-1. 인접성(neighbors)이 전부다
- 병력은 **인접한 province로만** 한 번에 이동할 수 있다.
- 따라서 지도는 실질적으로 **노드 = province, 간선 = 인접 관계**인 그래프다.
- 해안 province는 바다 province와 인접하지만, **Port가 있어야** 바다로 나갈 수 있다. **[원작]**

### 4-2. Province의 세 가지 상태
```
████  = 내 국가
░░░░  = 다른 국가 (아군/중립국/적국은 외교 상태로 구분)
▒▒▒▒  = 미점유 중립 지역
```
중립 지역은 병력 없이 비어 있거나 소규모 저항만 있는 상태로, 이동해 들어가면 점령된다. **[추정: 중립 지역 방어 병력 유무는 시나리오 의존]**

## 5. 국가(Civilization)

```
Civilization
├─ name, tag            (예: "Korea", KOR)
├─ color                (지도 채우기 색)
├─ flag                 (국기 이미지)
├─ capital              (수도 province id)
├─ provinces[]          (소유 province 목록)
├─ treasury             (국고)
├─ income               (매 턴 수입 = 세금 − 유지비)
├─ movement_points      (이번 턴 남은 MP)
├─ relations{}          (국가별: WAR / PEACE / PACT(남은 턴) / ALLIANCE)
├─ alliance_members[]
├─ overlord             (내가 종속국이면 종주국)
├─ vassals[]
├─ capital_lost_turns   (수도 상실 후 경과 턴)
└─ is_player / ai_profile
```

화면 상단 바에는 이 중 **국고(+증감), 총인구, 총병력, 턴 번호** 정도만 압축되어 표시된다.
"국가 정보" 버튼을 누르면 province 수, 동맹 목록, 전쟁 중인 국가 목록, 종속국 목록 등이 간단한 리스트로 나온다.

## 6. 병력 — 유닛이 아니라 숫자

- 보병/전차/궁수 같은 **병종 구분이 없다.** 숫자 `350`, `1,200`, `7,500` 자체가 군대다.
- 엔진 입장에서 군대는 `(province_id, civ_id, amount)` 세 값뿐이다.
- 한 province에 **여러 국가의 병력**이 동시에 존재할 수 있다 (예: 동맹군 주둔, 전투 직전 상황). **[추정]**
- 같은 국가 병력이 같은 province에 모이면 **그냥 숫자가 합쳐진다.**

```
A: 600 ──► B(400 주둔)   ⇒   B: 1,000
```

## 7. 턴 구조와 Movement Points

### 7-1. 한 턴의 흐름 **[원작: 라운드 전에 명령 제출, MP로 명령 수 제한, 국가 행동이 정해진 순서로 실행]**

```
┌─────────────── 계획 단계 (플레이어 입력) ───────────────┐
│ 1. 지도 확인 (Map Mode 바꿔가며 정찰)                  │
│ 2. Move 명령들 예약                                    │
│ 3. Recruit / Disband 예약                              │
│ 4. Build 예약                                          │
│ 5. Diplomacy 명령 예약                                  │
│ 6. [END TURN]                                          │
└────────────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────── 해결 단계 (세계 시뮬레이션) ─────────────┐
│ a. AI 국가들도 각자 명령 결정                          │
│ b. 국가별 행동을 정해진 순서대로 실행                  │
│    - 외교 → 모집/해산 → 건설 → 이동 [추정: 순서]       │
│ c. 같은 province에 적대 병력이 만나면 전투             │
│ d. 전투 결과로 소유권 변경, 색 갱신                    │
│ e. 수도 상실 카운트 갱신 → 3턴 넘으면 문명 소멸        │
│ f. 경제 갱신: 세금 수입 − 유지비 → 국고                │
│ g. 인구 성장 [추정]                                    │
│ h. 협정(PACT) 남은 기간 감소                           │
│ i. MP 리셋, 턴 번호 +1                                 │
└────────────────────────────────────────────────────────┘
```

### 7-2. Movement Points (MP)
- **[원작]** 각 턴에는 행동 가능량인 MP가 있고, 명령을 제출할 때마다 MP를 소모한다.
- 그래서 "이번 턴에 무엇을 다 할 수 있나"가 아니라 **"이번 턴에 어떤 명령을 우선할 것인가"** 를 고르는 게임이 된다.
- **[추정]** MP 총량은 국가 규모(province 수 등)에 따라 커지는 구조로 느껴진다. 큰 나라일수록 동시에 여러 전선을 운영할 수 있지만, 그래도 모든 국경을 다 움직이지는 못한다.
- **[추정]** 명령별 MP 비용 예시 (구현용 기본값):

| 명령 | MP 비용(예) |
|---|---|
| Move (내 영토 내) | 1 |
| Move (공격) | 2 |
| Recruit | 1 |
| Disband | 1 |
| Build | 2 |
| 외교 명령 | 1~2 |

## 8. 명령 상세

### 8-1. Move (이동 / 공격)
- **[원작]** Move 하나가 **내 영토 내 이동**과 **타국 province 공격**을 모두 담당한다.
- 이동 대상 province에 따라 결과가 달라진다:

| 대상 province | 결과 |
|---|---|
| 내 영토 | 병력 합류 |
| 동맹국 영토 | 통과/주둔 **[추정]** |
| 중립(미점유) 지역 | 진입 → 점령 |
| 전쟁 중인 국가 영토 | 전투 발생 |
| 평화/협정 상태 국가 영토 | 이동 불가 (먼저 WAR 선언 필요) |
| 바다 (Port 있는 province에서) | 해상 병력이 됨 |

- 슬라이더로 **일부만** 보낼 수 있다. 1,000 중 600만 보내고 400은 남겨 수비 — 이게 기본 운영 감각.

### 8-2. Recruit (모집)
- **[원작]** province의 **인구를 기반**으로 병력을 모집한다. **돈이 들고**, 그 province의 **인구가 감소**한다.
```
Province 서울
Population: 10,000,000 → 9,999,700
Army:       500        → 800
Treasury:   1,250      → 1,190
```
- 즉 인구 = 병력의 원료. 인구가 많은 province(수도권, 대도시)가 전략적 핵심이 된다.
- **[추정]** 모집 가능 최대치는 province 인구와 국고 중 작은 쪽에 묶인다.

### 8-3. Disband (해산)
- 병력을 줄인다. **[원작]** 해산하면 **군사 유지비가 감소**한다.
- 국고가 바닥났을 때, 전쟁이 끝난 뒤 후방 병력을 정리할 때 쓴다.
- **[추정]** 해산된 병력 일부가 인구로 돌아가는 구현도 자연스럽다.

### 8-4. Build (건설) **[원작: Fort, Watch Tower, Port]**

| 건물 | 효과 | 쓰임 |
|---|---|---|
| **Fort** (요새) | 해당 province 방어력 상승 | 국경 요충지, 수도 주변 |
| **Watch Tower** (감시탑) | 주변 province의 병력 숫자를 볼 수 있게 함 | Fog of War 상태에서 정찰 |
| **Port** (항구) | 병력을 바다로 내보낼 수 있게 함 | 해외 원정의 필수 조건 |

- 도시 건설 시스템이 아니라, **province에 붙는 작은 스위치**에 가깝다.
- **[원작]** 수도는 **기본 건물을 갖고 시작**한다.

## 9. 전투

### 9-1. 언제 일어나나
- 서로 **전쟁 중인** 두 국가의 병력이 **같은 province**에 들어오면 해결 단계에서 전투가 처리된다.
- 플레이어는 전투를 조종하지 않는다. **입력은 숫자, 출력도 숫자.**

### 9-2. 전투에 들어가는 요소
```
공격 병력 수
방어 병력 수
+ 지형 보정          (산/숲 등은 방어 유리) [추정]
+ Fort 보정          (방어측) [원작: Fort가 방어력 상승]
+ 수도 보정          (공격·방어 양쪽 보너스) [원작]
+ 무작위성           (약간의 랜덤) [추정]
```

### 9-3. 결과 예시
```
한국 공격 800  vs  일본 방어 500
        ↓
양쪽 손실 계산
        ↓
한국 500 생존 / 일본 0
        ↓
province 소유권 → 한국, 색이 한국 색으로 바뀜
```

- 공격이 실패하면 공격 병력이 소멸하거나 일부만 남고, 소유권은 그대로다.
- 방어측이 이기면 방어 숫자가 깎인 채로 남는다 → 다음 턴 재공격의 여지가 생긴다.

### 9-4. **[추정]** 구현용 간단 공식
```
atk_power = attackers × (1 + capital_bonus_atk) × rand(0.9, 1.1)
def_power = defenders × (1 + terrain_bonus + fort_bonus + capital_bonus_def) × rand(0.9, 1.1)

if atk_power > def_power:
    attackers_left = attackers × (1 − def_power / atk_power)
    defenders_left = 0
    owner = attacker
else:
    defenders_left = defenders × (1 − atk_power / def_power)
    attackers_left = 0
```

## 10. 점령과 색깔 변화

- 방어 병력이 0이 되고 공격 병력이 남으면 **province 소유권이 넘어간다.**
- 지도에서 그 칸의 색이 즉시 바뀐다. 이게 이 게임의 가장 큰 보상 피드백이다.
- 세계정복의 진행 상황은 결국 세 가지 면적의 변화다:
```
내 색깔 영역 ███████████
적 색깔 영역 ░░░░░░░░
중립 영역   ▒▒▒▒▒▒▒
```

## 11. 수도 (Capital) — 원작의 독특한 승패 축

**[원작]**
1. 각 국가에는 수도가 하나 있다.
2. 수도는 **공격·방어 양쪽에 보너스**를 갖고, **기본 건물**을 갖고 있다.
3. **수도를 잃은 상태가 3턴 지속되면 그 문명은 소멸**한다.
4. **다른 문명의 수도를 점령하면 그 문명의 province 전체를 얻는다.**

이 때문에 전쟁의 형태가 바뀐다.
```
❌ 영토 100개를 하나씩 다 점령
✅ 국경 돌파 → 수도로 직행 → 수도 점령 → 나라 전체 흡수
```
- 공격자는 "수도까지의 최단 경로"를 노리고, 방어자는 수도 주변에 병력과 Fort를 쌓는다.
- 수도를 빼앗긴 쪽은 **3턴 안에 탈환**해야 살아남는다 — 이 3턴이 극적인 반격 구간이 된다.

## 12. 외교

**[원작]** 버튼 몇 개로 국가 관계를 조작하는 구조.

| 명령 | 효과 |
|---|---|
| **WAR** | 대상 국가와 전쟁 상태로 진입. 이제 서로의 province를 공격할 수 있다. |
| **PEACE** | 전쟁 중인 상대에게 평화 제안. 상대(AI)가 수락해야 성립. |
| **PACT** | 불가침 협정. **일정 기간 서로 공격할 수 없다.** |
| **ALLIANCE** | 동맹. 전쟁에서 서로 도울 수 있다. |
| **KICK** | 동맹에서 상대를 제외(동맹 해제). |
| **SUPPORT** | 상대 국가에 **돈을 지원**. |
| **VASSAL** | 상대를 종속국으로 만듦. |
| **ANNEX** | 종속국을 합병해 내 영토로 편입. |

### 12-1. 외교 화면 흐름
```
다른 나라 province 탭
   → [Diplomacy]
   → 상대 국기 + 현재 관계(PEACE / WAR / PACT n턴 / ALLY) 표시
   → 버튼 줄: WAR | PEACE | PACT | ALLIANCE | KICK | SUPPORT | VASSAL | ANNEX
   → (제안형 명령은) 다음 해결 단계에서 AI가 수락/거절 → 알림
```

### 12-2. 종속국 (Vassal)
- 국가를 완전히 없애는 대신 **종속국으로 남길 수 있다.**
- 종속국은 지도에 원래 색으로 남아 있지만 종주국 편이다. **[추정: 종주국 전쟁에 자동 참전]**
- 나중에 **ANNEX**로 흡수하면 그 province들이 한 번에 내 색으로 바뀐다.

## 13. 바다와 해상 이동

**[원작]**
- **Port가 있는 province에서만** 병력을 바다로 내보낼 수 있다.
- 바다에 들어간 병력은 바다 province를 따라 이동하고, 다른 해안 province에 **상륙**할 수 있다.
- **바다 위 병력은 육지보다 유지비가 더 높다.**

```
유럽 해안(Port) ─► 지중해 ─► 지중해 ─► 북아프리카 해안 (상륙/공격)
     1,500          1,500      1,500         전투
```
- 그래서 바다 원정은 "짧고 굵게" 해야 한다. 오래 띄워 두면 국고가 빠르게 녹는다.

## 14. 경제

**[원작]** 세금 수입은 **문명의 총인구와 경제**를 기반으로 하고, **군사 유지비**가 여기서 빠져나간다.

```
수입  = f(총인구, 경제)
지출  = 육상 병력 × 육상 유지비 + 해상 병력 × 해상 유지비(더 비쌈)
국고 += 수입 − 지출
```

- 상단 바의 `💰 1,250 (+85)` 처럼 **국고와 턴당 증감**이 표시된다.
- 증감이 음수가 되면 빨간색 경고. **[추정]** 국고가 0 아래로 내려가면 모집 불가 / 강제 해산 / 사기 저하 같은 페널티.
- 이 게임의 경제는 결국 하나의 순환이다:
```
나라가 커짐 → 인구↑ → 수입↑ → 모집↑ → 병력↑ → 정복↑ → 나라가 커짐
                                      └→ 유지비↑ (브레이크)
```

## 18. 한 판의 전형적인 전개 (예: 대한민국 선택)

```
턴 1~5    : 국경 정리. 수도(서울)에 Fort, 부산에 Port 건설.
            인구 많은 province에서 Recruit. 일본과 PACT.
```

```python
def end_turn(world, orders_by_civ):
    for civ in world.ai_civs:
        orders_by_civ[civ] = ai_decide(world, civ)

    for civ in ordered(world.civs):             # 정해진 순서
        for o in orders_by_civ[civ]:
            if o.type == DIPLOMACY: apply_diplomacy(world, o)
    for civ in ordered(world.civs):
        for o in orders_by_civ[civ]:
            if o.type in (RECRUIT, DISBAND, BUILD): apply_economy_order(world, o)
    for civ in ordered(world.civs):
        for o in orders_by_civ[civ]:
            if o.type == MOVE: move_army(world, o)  # 적대 병력과 만나면 battle()

    for p in world.provinces:
        resolve_battles(world, p)                # 승자에게 소유권
        if p.is_capital and p.owner != p.original_capital_owner:
            transfer_all_provinces_if_rules(world, p)

    for civ in world.civs:
        civ.capital_lost_turns = civ.capital_lost_turns + 1 if lost_capital(civ) else 0
        if civ.capital_lost_turns >= 3: eliminate(world, civ)
        civ.treasury += tax(civ) - upkeep(civ)   # 해상 병력 유지비 가중
        tick_pacts(civ)
        civ.mp = max_mp(civ)

    grow_population(world)
    world.turn += 1
```

## 22. 정리

원작 Age of Civilizations는

- **province(칸)** 위에
- **국가 색(소유)** 과 **숫자(병력)** 를 올려 두고,
- **MP로 제한된 명령**을 턴마다 제출하면
- 세계 전체가 **동시에 해결**되며,
- **수도**라는 특별한 승패 축과 **간단한 외교 버튼**이 흐름을 비틀어 주는

아주 단순하지만 중독적인 세계정복 게임이다.
화면에서 실제로 움직이는 것은 사람도 탱크도 아닌 **숫자와 색깔**이고, 그 숫자와 색깔이 세계지도를 덮어 가는 과정 자체가 이 게임의 전부다.
